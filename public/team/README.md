# Team photos

Put portrait photos for the Meet the Team page (`/team`) in this folder, then set the file name in
`src/data/team.ts` (the `photo` field), for example `photo: 'shivansh.jpg'`.

- Portrait orientation works best (4:5, for example 800 x 1000 px). JPG, PNG or WebP.
- Keep each file under about 300 KB so the page loads fast.
- Use lower-case file names without spaces (`vivek-rajput.jpg`).
- Until a photo is set, or if the file is missing, the card shows a placeholder avatar with initials.
